# Security policy

Only the latest release is supported for security fixes.

Report vulnerabilities through [GitHub private vulnerability reporting for
cutgraph/cutgraph](https://github.com/cutgraph/cutgraph/security/advisories/new).
Please keep vulnerability details out of public issues and discussions.

Include the affected version, operating system, reproduction steps, expected
and observed behavior, potential impact, and any suggested mitigation. Remove
credentials, private media, and other personal data from attachments.

We aim to acknowledge reports within 7 days. Investigation and fix timing depend
on severity and reproducibility; we will coordinate updates and disclosure with
the reporter through the private report.
